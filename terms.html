2. Privacy Policy

Here's a genuinely complete account of what happens to your data on this Site — not boilerplate, an actual description of how this specific site works.

What we don't do

  • We don't use cookies.
  • We don't run analytics or tracking scripts of any kind.
  • We don't have user accounts, so we don't store passwords, profiles, or login data.
  • We don't have a server-side backend — this Site is static files served by GitHub Pages.

What does happen

  • GitHub Pages hosting. Like any web host, GitHub Pages' infrastructure receives standard request data (IP address, browser type, requested page) to serve you the Site. That's governed by GitHub's own privacy statement, not something we control or receive.
  • Live GitHub stats. Some pages (project cards, the Community page) fetch public data directly from the GitHub API from your browser — star counts, contributor lists, open issues. This is a request from your browser straight to GitHub's API; we don't proxy or log it ourselves, but GitHub will see the request came from your IP address, same as visiting github.com directly.
  • Google Fonts. This Site loads typefaces from Google Fonts' CDN. Google may log standard request data for that. If you'd rather avoid this, most ad blockers and privacy extensions block it without breaking the Site (it just falls back to your system font).
  • Contact & newsletter form. The "Get in touch" and newsletter signup on the homepage don't submit to a server we run — clicking them opens your own email client with a pre-filled message. We only see what you actually choose to send us by email, and it goes to that inbox like any other email.
  • Theme preference. If you switch between light and dark mode, that choice is saved in your browser's local storage so we can remember it next visit. This never leaves your device and isn't accessible to us.

Children's privacy

This Site isn't directed at children and we don't knowingly collect data from anyone, let alone children specifically — see above, we largely don't collect data at all.

Your rights

Since we don't hold personal data about you beyond what's inherent to normal web hosting (see above), there isn't a personal-data database to request access to or deletion from. If you've emailed us directly, you can ask us to delete that correspondence at any time — write to the address below.
