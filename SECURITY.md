# Security Policy

Link with iQ is a small, independently-run static site and set of open-source projects. There's no dedicated security team — reports go directly to the maintainer.

## Reporting a vulnerability

Email **linkwithiq@proton.me** with what you found. Please include:

- What the issue is and roughly how severe you think it is
- Steps to reproduce it, if you have them
- Which repo/project it affects (this site, or one of the linked project repos under [github.com/linkwithiq](https://github.com/linkwithiq))

You should get a reply acknowledging the report. Since this is solo-maintained, response time depends on what else is going on — but genuine security issues get priority over everything else in the backlog.

Please don't open a public issue for anything that looks like a real vulnerability until it's been looked at — email first.

## Scope

This covers the code in this repository and the linked project repositories under the `linkwithiq` GitHub org. It doesn't cover GitHub Pages' own infrastructure (report those to GitHub directly) or third-party services this site links to but doesn't control.

## Machine-readable version

A [RFC 9116](https://www.rfc-editor.org/rfc/rfc9116)-format `security.txt` is also published at [`/.well-known/security.txt`](https://linkwithiq.github.io/.well-known/security.txt) for automated tooling.
