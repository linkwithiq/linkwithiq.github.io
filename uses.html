Uses

What this site is actually built with, and what it deliberately isn't. No build step to hide behind — this is the whole stack.

Stack

Plain HTML, CSS, and JavaScript — no framework, no bundler, no build step. Every .html file is a complete, independent document sharing one stylesheet (styles.css) and one script (script.js). Locally it runs on nothing fancier than python3 -m http.server.

Hosting

GitHub Pages, serving static files directly from the repo. No server-side backend, no database — which is also why the privacy policy can honestly say there's no server-side data collection: there's no server to collect anything.

Design

Every color, spacing, and type value is a CSS custom property in styles.css — --ink, --cream, --rust, --signal, and the spacing/radius scale, so the whole look can be retuned from one place. Type is Oswald for headings, Inter for body text, and JetBrains Mono for labels and code, loaded from Google Fonts. The logo mark exists as hand-traced SVG paths in four color variants rather than a raster export, so it stays crisp at any size and can recolor with currentColor.

Live data

Where the site shows real-time information — star counts and last-updated dates on project cards, the good-first-issue feed, and contributor avatars on the Community page — it's fetched directly from the browser to the public GitHub API. Nothing is proxied or logged on this end; see the Privacy Policy for exactly what that means.

What's deliberately not here

No analytics or tracking scripts of any kind. No cookies. No client-side framework (React, Vue, or otherwise). No CMS. No advertising. No third-party embeds beyond Google Fonts and the GitHub API calls described above. This isn't a placeholder list to fill in later — it's the current, accurate state of the stack, and it'll be updated here the day any of it changes.

Full detail

The complete technical writeup — deploy steps, known bugs and their fixes, the full design token list — lives in the repository's README on GitHub.
