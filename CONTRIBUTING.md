# Contributing to Link with iQ

This mirrors the live [Community & Contributing](https://linkwithiq.github.io/community.html) page — that page is the one being actively edited; open an issue if this file drifts out of sync with it.

Link with iQ is built in the open. Anyone can file an issue, pick one up, or point out a problem worth solving — no invitation needed.

## Three ways in

**1. Grab an issue.** Browse issues tagged [`good first issue`](https://linkwithiq.github.io/community.html#good-first-issues) — pulled live from GitHub across all repos under this org — or dig through any repo's open issues directly.

**2. Suggest a problem.** Have a real problem you think fits what's being built here? [Send it in](mailto:linkwithiq@proton.me) — most projects here started as someone else's suggestion.

**3. Just ship something.** Everything's MIT-licensed and open (see [LICENSE](LICENSE)). Fork a repo, build on it, ship your own version — no permission needed.

## Before you open a PR

- Check the repo's own `LICENSE` file — it's typically MIT, but confirm per-repo.
- Code generated with AI assistance is welcome, but goes through the same review as anything else before it ships — see the [AI-use policy](https://linkwithiq.github.io/policy.html#use-of-ai-in-our-work).
- Accessibility bugs (keyboard nav, screen readers, contrast) are treated as real bugs, not optional polish.

## Reporting a security issue

Don't open a public issue for anything that looks like a real vulnerability — see [SECURITY.md](SECURITY.md) for how to report it privately first.

## Questions

Fastest way to reach the maintainer: **linkwithiq@proton.me**, or open an issue directly on the relevant repo.
