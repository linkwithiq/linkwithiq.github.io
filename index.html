Our mission

Practical technology, built responsibly

To research, develop, and share practical technology that solves real-world problems — while prioritizing privacy, accessibility, simplicity, openness, and human benefit. Read the full mission and principles.

01 / PRIVACY FIRST

Considered by design, not bolted on

We minimize unnecessary data collection and prefer approaches that keep data under the user's control.

02 / OPEN BY DEFAULT

Open as much as responsibly possible

Code, research, and documentation are public so others can learn from, fork, and improve on the work.

03 / REAL-WORLD IMPACT

Problem → research → build → improve

A project doesn't need to be revolutionary to be valuable — solving a small problem well is enough.

Common questions

FAQ

The things people usually ask before reaching out.

Is everything here actually free?

Yes. Every project and resource we publish is free to use, and the code is open so you can inspect, fork, or build on it. We're not selling access — the goal is for it to be picked up and used.

Can I suggest a problem for you to work on?

Please do — that's exactly how most of these projects start. Use the "Submit a problem" link in Resources, or just email us directly. We read everything, even if we can't take on every idea right away.

Can I contribute to a project?

Everything lives in the open on GitHub. Check the Contributor Playbook in Resources for how we plan and ship, then open an issue or pull request on the project you're interested in.

Who's actually behind Link with iQ?

Link with iQ is owned and maintained by Ajit (asrbmy). See the About section below for more.

Do you take on paid client work?

Not the focus right now — this is a research and development organization, not an agency. If that changes we'll say so here. In the meantime, get in touch and we'll point you in the right direction either way.
